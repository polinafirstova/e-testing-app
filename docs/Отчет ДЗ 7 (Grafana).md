# Домашнее задание №7. Grafana

## 1. Источники данных

В качестве источника данных для Grafana используется VictoriaMetrics. Она подключена через стандартный плагин Prometheus по внутреннему DNS Kubernetes. Это позволяет Grafana напрямую обращаться к базе метрик внутри кластера.

## 2. Панели для мониторинга приложения

1. **RPS (Questions API)** — `sum(rate(app_questions_request_duration_seconds_count[5m]))`.
   - Показывает интенсивность трафика, сколько запросов в секунду обрабатывает API. Позволяет увидеть рост нагрузки или ее резкое падение (что может указывать на проблему).
   - ![RPS (Questions API)](<../screenshots/ДЗ 7 (Grafana)/rps.png>)

2. **Error Rate (5xx)** — `sum(rate(...{status="500"}[5m])) / sum(rate(...[5m])) * 100`.
   - Показывает процент запросов, завершившихся ошибкой 500. Главный индикатор деградации сервиса. На панели настроены пороги для визуального выделения критических значений.
   - ![Error Rate (5xx)](<../screenshots/ДЗ 7 (Grafana)/error_rate.png>)

3. **p95 Latency** — `histogram_quantile(0.95, sum(rate(..._bucket[5m])) by (le))`.
   - Показывает время ответа, 95-й процентиль времени ответа, насколько быстро сервис отвечает большинству пользователей. Рост p95 сигнализирует о проблемах с производительностью.
   - ![p95 Latency)](<../screenshots/ДЗ 7 (Grafana)/p95_latency.png>)

4. **Memory Usage (Heap)** — `nodejs_heap_size_used_bytes`.
   - Показывает объем памяти, занятый объектами приложения. Позволяет отслеживать утечки памяти и приближение к лимиту (OOM).
   - ![Memory Usage (Heap)](<../screenshots/ДЗ 7 (Grafana)/memory_usage.png>)

5. **Event Loop Lag** — `nodejs_eventloop_lag_seconds`.
   - Показывает время, на которое зависает обработка запросов. Рост задержки указывает на блокировку event loop и замедление всего приложения.
   - ![Event Loop Lag](<../screenshots/ДЗ 7 (Grafana)/event_loop_lag.png>)

6. **SLA (Availability)** — `(1 - (sum(rate(...{status="500"}[5m])) / sum(rate(...[5m])))) * 100`
   - Показывает текущий процент успешных запросов к API. Настроены цветовые пороги: зеленый (> 95%), желтый (80-95%), красный (< 80%). Позволяет мгновенно понять, выполняются ли SLO/SLA.
   - ![SLA (Availability)](<../screenshots/ДЗ 7 (Grafana)/sla.png>)
